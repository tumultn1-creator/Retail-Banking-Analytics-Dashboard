# Retail Banking Analytics Dashboard

## Overview
This project is an end-to-end retail banking analytics solution designed to analyze customer behavior, financial performance, lending activity, credit risk, and transaction trends. The project uses Python to generate banking datasets, SQL for data storage and management, and Power BI to create an interactive dashboard for business insights.

## Business Objective
The goal of this project was to develop a dashboard that allows stakeholders to monitor key banking metrics and better understand customer activity, deposits, loans, credit quality, and transaction patterns.

## Tools & Technologies
- **Python** - Data generation and preparation using Pandas and Faker
- **SQL** - Data storage, querying, and data management
- **Power BI** - Data modeling, visualization, and dashboard development
- **DAX** - Calculated measures and KPI creation

## Dataset
A synthetic retail banking dataset was created to simulate real-world banking operations. The dataset includes:

- **Customers** - Customer demographics and account information
- **Accounts** - Account types and deposit balances
- **Transactions** - Customer transaction activity and transaction amounts
- **Loans** - Loan types and loan amounts
- **Credit Scores** - Customer credit risk information

Dataset Size:
- 50,000 customers
- 94,000+ accounts
- 15,000 loans
- 1.4M+ transactions
- 50,000 credit score records

## Dashboard Features

### Customer Analysis
- Total customer count
- Customers by account type
- Credit score distribution

### Deposit Analysis
- Total deposits
- Deposit distribution across account types

### Loan Analysis
- Total loan portfolio
- Loans by loan type
- Average loan amount by loan type

### Transaction Analysis
- Total transaction volume
- Transactions by type
- Transaction amount by type

## Key Insights
- Analyzed customer activity across multiple banking products.
- Evaluated deposit distribution and overall financial activity.
- Compared loan volume and average loan sizes across loan categories.
- Examined customer credit score distribution to understand risk levels.
- Analyzed transaction behavior and money movement patterns.
